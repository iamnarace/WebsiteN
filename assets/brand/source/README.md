# 1Touch IT Logo Source Files

This folder preserves the three original uploaded PNG logo files as Base64 text files:

- Logo1.png.base64
- Logo2.png.base64
- Logo3.png.base64

Decode each file from Base64 back to PNG before implementation. Keep the originals and create separate web-optimised versions for the header, footer, favicon and social-share image. Do not redraw, stretch or substitute the approved logo without permission.
